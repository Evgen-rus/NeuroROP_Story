# Сообщение для первого запуска Codex

Работаем над отдельным проектом `NeuroROP Story`.

Сначала прочитай `AGENTS.md`, затем документы в порядке, указанном там. Не меняй продуктовый смысл и storyboard без моего согласования.

Задача первого цикла:
1. проверь текущее состояние проекта и сборку;
2. составь короткий план реализации;
3. доведи Scenes 01–04 до визуально сильного desktop-first прототипа;
4. используй `references/raw/` только как локальные визуальные референсы — реальные компании/ФИО не переносить и raw PNG не включать в приложение/build;
5. соблюдай orchestration из `AGENTS.md`: primary lead остаётся владельцем архитектуры и приёмки, Luna workers вызывай только когда это экономит контекст/время;
6. после изменений выполни typecheck/build и проверь, что raw references не попали в `dist`;
7. в финале дай краткий отчёт: CHANGES / FILES / VERIFICATION / RISKS / NEXT.

Не пытайся за один проход «набить» все 13 сцен. Качество и continuity первых 4 сцен важнее количества.
