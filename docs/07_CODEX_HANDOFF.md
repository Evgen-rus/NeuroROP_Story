# 07 — Codex handoff

## Задача
Довести этот starter до premium интерактивной scrollytelling-презентации НейроРОПа, строго следуя `docs/02_STORYBOARD.md`.

## Первый проход
1. `git status --short` (если проект уже под git).
2. Прочитать `AGENTS.md`.
3. Прочитать `docs/01_PRODUCT_BRIEF.md` и `docs/02_STORYBOARD.md`.
4. Проверить `npm run typecheck` и `npm run build`.
5. Составить короткий implementation plan без изменения смысла сцен.
6. Сначала реализовать Scenes 01–04 до визуально сильного состояния.
7. Только после этого продолжать 05–13.

## Главный приоритет
Не «дописать все 13 сцен», а добиться ощущения дорогой, цельной истории:
- ясный hook за 5–10 секунд;
- continuity между сценами;
- UI выглядит как настоящий продукт;
- motion помогает понять смысл.

## Разрешённые субагенты
Следовать `AGENTS.md`. Primary = Sol Medium. Использовать Luna workers экономно и только на независимых областях.

## Что отчитаться пользователю после первого цикла
- что сделано;
- какие сцены готовы;
- какие решения приняты;
- какие screenshots использованы как reference;
- результаты typecheck/build;
- что осталось;
- 2–4 screenshot/visual checkpoints, если среда умеет их сделать.
