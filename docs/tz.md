Сначала прочитай AGENTS.md и обязательные docs проекта. Соблюдай существующую orchestration policy: основной lead принимает архитектурные и продуктовые решения; Luna-workers используй только там, где это реально экономит контекст/время. ЗАДАЧА

Нужно сделать второй качественный проход презентации NeuroROP Story.

Текущие 13 сцен уже работают, typecheck/build проходят. Не нужно просто добавлять больше fade-анимаций. Главная задача этой итерации:

1. превратить набор отдельных сцен в цельную scrollytelling-историю с визуальной continuity;
2. заменить текущий текст на финальный B2B copy;
3. сильнее показать две стороны продукта:
   - РОП видит риски и понимает, куда вмешаться;

4. добавить смысл «НейроРОП — усилитель, а не замена РОПа или менеджера»;
5. показать feedback loop;
6. аккуратно добавить реальные кейсы;
7. показать, что НейроРОП способен выявлять перегруз отдела продаж.

1. ГЛАВНЫЙ ПРИНЦИП MOTION
==================================================

Сейчас многие сцены визуально выглядят как:

экран
→ следующий экран
→ следующий экран

Нужно перейти к принципу:

ОДИН ОБЪЕКТ
→ меняет состояние
→ становится частью следующей сцены
→ развивается дальше.

Motion должен объяснять причинно-следственную связь.

Не делать одинаковый fade-up на каждой сцене.

Главная визуальная идея:

ВСЯ КОМАНДА
↓
ОДИН МЕНЕДЖЕР
↓
ОДНА СДЕЛКА
↓
КОНТЕКСТ СДЕЛКИ
↓
РИСК
↓
РЕШЕНИЕ РОПа
↓
ДЕЙСТВИЕ МЕНЕДЖЕРА
↓
РЕЗУЛЬТАТ
↓
ПОВТОРНАЯ ПРОВЕРКА

Сохраняем 13 пунктов StoryRail, но визуально объединяем их в 4 большие непрерывные главы.

→ следующий checkpoint.

ArrowUp / ArrowLeft

P
→ presentation mode.

В presentation mode:
- можно скрыть StoryRail;
- оставить минимум навигационного UI;
- не ломать обычный scroll.

Escape
→ выйти из presentation mode.

11. VISUAL POLISH
==================================================

Уменьшить ощущение:
«большая белая карточка внутри каждой сцены».

Не каждая сцена обязана жить внутри одного одинакового visual-card.

Особенно:

Context
Risk
Feedback Loop

могут частично жить прямо на основном фоне страницы.

Сохраняем visual language настоящего НейроРОПа:
- белый;
- холодный светлый фон;
- синий;
- красный / жёлтый / зелёный только по смыслу.

Не копировать фирменный стиль Anthropic.

Берём у них только принцип:
scrollytelling,
continuity,
progressive disclosure,
interactive explorer.
