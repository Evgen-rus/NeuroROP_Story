# 03 — Design system

## Визуальное направление
Светлый research/product style. Много воздуха. Интерфейс НейроРОПа — главный визуальный материал, но не показывать целые скриншоты как слайды: реконструировать ключевые элементы компонентами.

Соотношение:
- ~60% product UI;
- ~40% абстрактная объясняющая графика.

## Цветовые роли
Не задавать «дизайнерскую радугу». Использовать:
- background: очень светлый холодный серо-голубой;
- surface: белый;
- text: глубокий тёмно-синий;
- primary: текущий продуктовый синий;
- danger: мягкий красный только для риска;
- warning: тёплый жёлтый только для контроля;
- success: зелёный только для нормы/подтверждения;
- borders: тонкие холодные серо-голубые.

## Типографика
Приоритет системному шрифту / Inter-like. Не тащить отдельный font asset без необходимости.
Headline: крупный, плотный, letter-spacing отрицательный.
Body: крупнее обычного SaaS, потому что страница используется как презентация.

## Сетка
Desktop 1440–1920:
- левый текстовый блок 35–40%;
- visual 60–65%;
- generous gutters;
- sticky visual.
На ключевых UI-сценах можно временно переходить в full-width.

## Карточки
Радиусы 16–28 px.
Тени минимальные.
Основная глубина создаётся white space + border + motion, а не shadow stack.

## Real UI reconstruction
Из референсов взять:
- структуру summary cards;
- светофор;
- список сделок;
- right detail panel;
- «Текущая ситуация»;
- «Контроль качества ведения»;
- «Фокус разбора»;
- «Дожим»;
- нижний input/voice/file/send;
- follow-up steps.

Не копировать:
- реальные названия компаний;
- реальные ФИО;
- приватные тексты без синтетической замены;
- технические internal status labels, если они отвлекают зрителя.

## UI names
Синтетические:
- «Менеджер А», «Менеджер Б»;
- «Компания Север», «Проект Альфа» или без названий вообще;
- ID сделки можно оставить числовым;
- суммы допустимо сохранять как реалистичные значения.

## Anti-patterns
Нельзя:
- шаблонный «AI gradient»;
- стеклянные неоновые панели;
- dark cyberpunk;
- 3D robot brain;
- бесконечные flying particles;
- длинные абзацы поверх анимации;
- одинаковый fade-up на каждой сцене.
