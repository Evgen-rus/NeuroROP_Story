# 06 — Privacy and reference assets

## Критично
`references/raw/` содержит скриншоты реального интерфейса, присланные пользователем. Они нужны **только как визуальные референсы для Codex**.

Никогда:
- не импортировать эти PNG из `src`;
- не копировать их в `public`;
- не включать в deploy/static hosting;
- не публиковать в issue/PR/README;
- не использовать реальные компании и ФИО из них в presentation UI.

## Карта референсов
- `01_rop_control_overview.png` — общий «Контроль РОП», метрики, таблица, detail panel.
- `02_rop_plan_and_recommendation.png` — план на сегодня + контекст/вывод AI + готовый сценарий.
- `03_team_daily_summary.png` — итог команды, светофор, менеджеры, summary.
- `04_deal_green_focus.png` — «Фокус разбора», вопросы менеджеру, сценарий разговора.
- `05_manager_tasks_overview.png` — задачи менеджера, просроченные, detail panel.
- `06_manager_deal_dozhim_entry.png` — entry point «Открыть дожим сделки».
- `07_dozhim_workspace.png` — modal Дожим, рычаг, сообщение, лайфхаки, input.
- `08_dozhim_workspace_query.png` — пользовательский текстовый вопрос в Дожиме.
- `09_followup_loading.png` — loading state продолжения переписки.
- `10_followup_scenario.png` — последовательный сценарий продолжения переписки.

## Что можно переносить
- композицию;
- паттерны карточек;
- иерархию;
- названия продуктовых блоков;
- агрегированные цифры, явно согласованные в storyboard;
- generic тексты/структуру после синтетической переписи.

## Анонимизация
Пример:
- `Пахомов Александр` → `Менеджер А`
- `ООО ...` → `Компания Север`
- имена клиентов → `Клиент`
- email/телефон/домены → никогда не переносить.

## Безопасная стратегия
Не редактировать PNG для показа. Лучше реконструировать UI компонентами React с синтетическими данными. Это и визуально качественнее, и безопаснее.
